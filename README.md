# AE2 - Simulador de Procesos y Memoria

Implementación en TypeScript de la Actividad de Evaluación 2 de Paradigmas y Lenguajes de Programación II.

## Tecnologías
- TypeScript
- Node.js
- Vitest
- V8 Coverage

## Instalación
```bash
npm install
```

## Pruebas
```bash
npm test
```

## Cobertura
```bash
npm run coverage
```

## Compilación
```bash
npm run build
```

La solución se organiza por responsabilidades: `Process`, `ContiguousMemoryManager`, `RoundRobinScheduler`, `MetricsCalculator` y `Simulator`.
